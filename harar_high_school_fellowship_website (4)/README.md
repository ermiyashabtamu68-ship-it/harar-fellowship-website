# Harar High School Fellowship Website

This is a functional starter website for Harar High School Fellowship.

## Included
- Home, About, Events, Partnership, Gallery, Announcements, Join Us and Contact pages
- Responsive mobile design
- Join Us form
- Partnership request form
- Demo admin dashboard
- Events and announcements rendering
- Browser localStorage for demo data

## Run it
Open `index.html` in a browser.

## Important
The forms currently save data only in the visitor's browser. For a real public website, connect the forms and admin dashboard to a backend such as Supabase or Firebase, then deploy the site to a host such as Vercel or Netlify.

## Next customization
Replace the placeholder content, email, social links, event dates, photos, colors and logo with the fellowship's real information.
